# 星墜彈幕 STARFALL DANMAKU

原創縱向彈幕射擊（STG）原型，使用 Unreal Engine 5.8 + C++。角色全部是男性。

遊戲介面有繁體中文和英文兩種，在標題選單最下面的「語言」切換（Z 或 ← →），設定會記住。字型是 Noto Serif TC（OFL 授權，可以隨遊戲一起散布，放在 `Fonts/`）。

### 標題選單

- **開始遊戲**：從第一面一路打下去，每打倒一個 Boss 會有關卡結算，再進入下一面。
- **Extra**：麻將主題的特別關卡，難度固定為 Extra。
- **Extra-IF**：「如果主角來不及拯救結界」的另一條路線，對手是上古四凶，難度固定為 Extra。
- **關卡練習**：選一面直接開始，打完 Boss 就結束。
- **符卡練習**：從所有 Boss（含 Extra、Extra-IF 的道中 Boss 和車輪戰）的符卡清單中選一張，直接開打，沒有道中和對話；結束後顯示收取成功或失敗，Z 回到清單。↑↓ 選擇、←→ 一次跳 10 張。
- **語言**：繁體中文 / English。

### 難度（選完模式之後，用 ↑ ↓ 選擇）

| 難度 | 彈數 | 發射間隔 | 子彈速度 | 殘機 |
|---|---|---|---|---|
| Easy 簡單 | ×0.45 | ×1.7 | ×0.78 | 4 |
| Normal 普通 | ×0.65 | ×1.35 | ×0.9 | 2 |
| Hard 困難 | ×0.85 | ×1.12 | ×1.0 | 2 |
| Lunatic 瘋狂 | ×1.0 | ×1.0 | ×1.05 | 2 |

數值定義在 `DanmakuTypes.h` 的 `GetDifficultyInfo()`，改那裡就能整體調整難度。發射時機用 `Every()`、彈數用 `Cnt()` / `Half()` 換算，環形彈會保持對稱，扇形彈維持奇數，正中間那發永遠瞄準自機。

### 道中

每一面的道中都不一樣（`DanmakuRoads.cpp`），長度大約：第一面 75 秒、第二面 90 秒、第三面 100 秒、第四面 110 秒、第五面 120 秒、第六面 60 秒、Extra 130 秒。後面的關卡敵人出現得更密、波次互相重疊；敵人的射擊會跟著難度變稀疏。

Extra-IF 的道中大約 115 秒，第 3000 幀出現道中 Boss。

**道中難度**：原本的道中（不論難度都一樣）現在是 Easy。Normal／Hard／Lunatic 會在同一段時間裡塞進更多紙人（快速的紙人隊伍密度 ×1.2／×1.4／×1.6）、射擊更頻繁（間隔 ×0.8／×0.67／×0.56）、每次射得更多（×1.3／×1.6／×2），只射一次的小兵在高難度會多射幾輪。Lunatic 從第二面開始，小兵被打倒時會朝自機回射一小撮子彈（Hard 只有第四面以後的式神會）。Extra 和 Extra-IF 的道中維持原樣。用 AI 量出來，Lunatic 道中自機周圍的子彈大約是原本的 4–6 倍。（`RoadTier()`、`RoadEvery()`、`RoadCount()`）

小兵血量：成群出現的紙人只有 3（紅色 9），停在原地射擊的式神是設定值的 75%，大型鬼火精靈（狐面）是 70%。血量倍率：第一面 ×1、第二面 ×1.1、第三面之後（包括 Extra 和 Extra-IF）都是 ×1.2，後面的關卡靠出怪密度變難，不靠血量。狐面出現時，畫面上其他小兵會消失，而且在狐面離開或被打倒之前不會再出其他小兵（`SpawnEnemy()`）。Extra 的紙人和式神被打倒時會爆出一小圈子彈。

Extra 的道中途中會出現**道中 Boss 玄**，他會介紹前方天和閣的主人一索、勸你撤退，並使用三張新符卡：逆符「五行逆轉」、數符「河圖洛書」、陣符「八門金鎖」。

### 劇情

四神結界會在天門之夜碎裂，守護者燁快要消失了，又離不開天宮。結界之力只追隨勝者，所以他用夢中的「天啟」讓五位守門人（天狼、千秋、嵐、墨竹、玄）各自收集一份力量，等有人一一打倒他們、把力量帶上天宮。對話會隨著關卡越來越長，也越來越接近真相：第五面的玄揭開謎底，第六面的燁親口說明目的。

Extra 是補充設定：五百年前，燁曾用結界的十三枚天印跟一索對賭並輸掉，那就是結界最初的裂痕。一索一直留著天印，是為了讓燁不要一個人硬撐、肯去找繼承人。「國士無雙」的十三名刺客就是這十三枚天印。

### 消不掉的子彈

- 「國士無雙」的刺客（每 3 秒一名，最多 13 名）、「君子之約」的菊花：Bomb 和被彈後的全屏清彈都消不掉，撞到自機也不會消失。
- 「大四喜」的風彈：Bomb 和全屏清彈都消不掉，只有打中你的那一顆會消失。
- 雷電和竹子的預警改成整條紅色區域加閃爍的中心線，越接近落下閃得越快。

### Boss 的保護機制

- 每張可以攻擊的符卡開始時，Boss 有 3 秒無敵（藍色護盾，血條上顯示「護盾」）。
- 每個 Boss 的最後一張符卡：蓮、蒼、雪的 Bomb 打不到 Boss（一般射擊照常有效）。晴的 Bomb 本來就沒有傷害。道中 Boss（Extra 的玄、Extra-IF 的凶獸）沒有這個保護，最後一張也能用 Bomb 打。

### Boss 在符卡中的移動

符卡的圖案如果不需要 Boss 待在特定位置，Boss 會像非符卡時一樣，每隔一陣子換個位置（`PatrolBoss()`）。需要固定位置的符卡（例如以 Boss 為中心的對稱圖案）Boss 會站著不動；西方「白虎嘯風」（白虎左右巡行）和凶符「窮奇之翼」（左右橫掃）一定會移動。

### 回血、回 Bomb

綜合了幾代東方的做法：

| 機制 | 條件 | 效果 |
|---|---|---|
| 分數獎命 | 分數到 1000 萬、3000 萬、6000 萬、1 億、1.5 億，之後每 1 億 | 殘機 +1 |
| 殘機碎片 | 收取符卡（沒被彈、沒用 Bomb）時，Boss 掉出一片 | 5 片 = 殘機 +1 |
| 靈符碎片 | 打破非符卡、擊破道中的大型鬼火精靈、每擦彈 250 次 | 3 片 = Bomb +1（蓮只要 2 片） |

殘機和 Bomb 最多各 8 個，超過的部分換成分數。碎片數量顯示在側欄。

### 耐久符卡

「君子之約」和「九蓮寶燈」是耐久符卡：Boss 無敵、血條鎖住，只能撐到時間結束，符卡獎勵固定 600 萬，不會隨時間減少。

### 對話

每個 Boss 對四位自機各有一段不同的對話，自機和 Boss 都有自己的個性：蓮熱血正直、蒼冷靜毒舌、晴悠哉愛吃、雪溫和、常跟人偶說話。第四面之後，打倒 Boss 還有一段戰後對話（`FBossDef::Ending`）。對話寫在 `DanmakuBosses.cpp`。

### 英文版

程式裡的文字都是中文，英文放在 `Tools/loc/en.txt`（每行「中文<Tab>英文」）。改了或加了中文字串之後：

1. `python Tools/loc/extract.py --check`：列出還沒翻譯的字串（`Tools/loc/missing.txt`）。
2. 把翻譯加進 `en.txt`。
3. `python Tools/loc/make_table.py`：重新產生 `Source/DanmakuSTG/DanmakuText_Table.inl`，再編譯。

沒翻譯的字串會直接顯示中文。

**Boss 血量**：全部大約是之前的一半，參考東方的設計：非符卡約 15–25 秒、符卡約 20–40 秒能打完。數值和對話都在 `DanmakuBosses.cpp`。

## 怎麼開始玩

1. 雙擊 `DanmakuSTG.uproject` 開啟編輯器（第一次開啟時如果問要不要重新建置，選「是」）。
2. 按上方的 **Play**，再點一下遊戲畫面，讓視窗取得鍵盤焦點。
3. 在 PIE 裡按 `Esc` 會結束遊玩，所以暫停鍵改用 `P`。

不需要在編輯器裡做任何設定，也不需要建立地圖：GameMode、HUD 和所有邏輯都由 C++ 自動建立。

## 操作

| 按鍵 | 功能 |
|---|---|
| 方向鍵 / WASD | 移動 |
| Shift | 低速模式（顯示判定點） |
| Z | 射擊／確定／推進對話 |
| X | Bomb（被彈後 8 幀內按下可以「決死」） |
| P | 暫停 |
| R | 暫停中或遊戲結束時重新開始 |

手把也可以用：左搖桿或十字鍵移動、A 射擊、B Bomb、LB/RB 低速。

## 目前內容

- 第一面道中：六波敵人（紙人式神、大型鬼火精靈）。
- Boss 出場前有一段帶立繪的對話。
- Boss 戰共 6 段：2 段非符卡、4 張符卡（見上表）。
- 擦彈（Graze）、靈力 1.00 到 4.00、得點道具、上方自動回收線。
- 角色動畫用網格變形：身體不動，衣襬、袖子會飄；長髮角色（天狼、蒼）的頭髮另外標出區域，從髮根到髮尾擺動。區域定義在 `DanmakuHUD.cpp` 開頭的 `FHairZone` 陣列。
- 符卡 Bonus：在時限內擊破、而且沒有被彈也沒有用 Bomb，才拿得到。
- 殘機和 Bomb、Game Over、通關結算。

## 檔案結構

```
Source/DanmakuSTG/
  DanmakuTypes.h      資料結構（子彈、敵人、道具、Boss 狀態…）
  DanmakuWorld.*      全部遊戲邏輯：固定 60 FPS、純 2D 計算
  DanmakuHUD.*        用 Canvas 繪製全部畫面
  DanmakuGameMode.*   建立遊戲世界、指定 HUD
Art/                  角色素材（執行時讀取 PNG）
Tools/make_art.py     素材生成腳本
```

### 常見修改要改哪裡

- **彈幕樣式**：`DanmakuWorld.cpp` 裡的 `Pattern_*` 函式。`T` 是該段開始後的幀數，用 `Fire` / `Ring` / `Fan` 發射子彈。
- **Boss 血量、時限、符卡名稱、對話**：`DanmakuBosses.cpp` 的表格，一面一個 Boss。
- **各面的彈幕**：`DanmakuStage2.cpp` ～ `DanmakuStage6.cpp`、`DanmakuStageEx.cpp`。特殊子彈行為（梅花種子、蓮花、刺客、延遲發射等）在 `DanmakuBehaviors.cpp`。
- **道中敵人出場時間**：`DanmakuRoads.cpp` 裡的 `RoadStage1()` ～ `RoadExtra()`，敵人射擊方式在同一個檔案的 `EnemyFire()`。
- **自機速度、判定、擦彈範圍**：`DanmakuTypes.h` 和 `UpdatePlayer()`。

### 為什麼不用 Actor 當子彈

同屏常有上千顆子彈，每顆都做成 Actor 會很卡。這個專案所有子彈都放在 `TArray<FBullet>` 裡，統一計算移動和碰撞（圓形距離判定），再用 Canvas 批次繪製。目前畫面上約 300 顆子彈時，FPS 仍有好幾百。

## 美術素材

角色素材用 Blender 製作：3D 模型配上卡通著色和外描邊，再用正交相機渲染成 2D 圖。臉部是 2D 貼圖，貼在 3D 頭上。

| 檔案 | 用途 |
|---|---|
| `Tools/blender/make_faces.py` | 畫臉部貼圖（眼睛、眉毛、嘴，每個角色有好幾種表情） |
| `Tools/blender/toon_lib.py` | 卡通材質、外描邊、頭髮、衣服等建模工具 |
| `Tools/blender/build_chars.py` | Ren 和 Sirius 的模型、立繪、Q 版精靈圖、紙人式神 |
| `Tools/blender/finish_art.py` | 裁切和縮放渲染結果，輸出到 `Art/` |
| `Tools/make_art.py` | 只產生鬼火精靈、子機和標題圖 |

全部重新生成（在專案資料夾執行）：

```
python Tools/blender/make_faces.py
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P Tools/blender/build_chars.py -- all
python Tools/blender/finish_art.py
```

**遊戲內角色也改用 Canva 圖：** 自機用 `Tools/canva/ren_back.png`（背影），Boss 用 `sirius.png`（全身）。匯入時會縮成 `Art/player_back.png` 和 `Art/boss_body.png`。

**戰鬥畫面的動畫用預先算好的 sprite sheet：** `python Tools/anim/make_sheets.py` 會把每個自機和 Boss 做成 `Art/<名字>_sheet.png`：5 列是傾斜姿勢（向左 2 級、正面、向右 2 級，整個人剛體旋轉，不會彎），12 欄是頭髮擺動。只有頭髮會動：在 `Tools/anim/sprite_specs.py` 指定的區域內、顏色接近髮色的像素才會被複製出來擺動，再疊回不動的身體上，所以手、腳、扇子、弓都不會變形。Boss 移動時會往移動方向傾斜。對話立繪是靜止的。

**敵人、子機、背景、UI、標題畫面也都是 Canva 圖：** 原圖放在 `Tools/canva/raw/`，執行 `python Tools/canva/make_assets.py` 會產生以下素材：

| 原圖 | 產生的素材 |
|---|---|
| 紙人式神 | `fairy_blue.png`；`fairy_red.png` 由藍色版調色而成 |
| 狐面鬼火 | `spirit.png` |
| 五芒星護符 | `option.png` |
| 夜間參道（俯視） | `bg_stage.png`，處理成上下無縫，在遊戲中捲動 |
| 星圖符卡背景 | `bg_spell.png`，Boss 開符卡時漸變切入 |
| 青海波花紋 | `ui_pattern.png`，鋪滿場地外圍 |
| 標題主視覺 | `title_art.png`，全螢幕標題畫面 |

**對話立繪目前用 Canva 生成的版本**（原圖在 `Tools/canva/ren.png`、`sirius.png`）。換新圖時，把透明背景的 PNG 用同樣檔名放進 `Tools/canva/`，再執行 `python Tools/canva/import_canva.py`。注意：如果之後又執行 `finish_art.py`，Blender 版立繪會把它蓋掉。

只想重做某一張，就把 `all` 換成 `ren_portrait`、`sirius_portrait`、`ren_sprite`、`sirius_sprite` 或 `enemies`。換表情：`ren_portrait angry`。

- 換圖很簡單：用同樣的檔名放進 `Art/`，重新開始遊戲就會讀取新圖。可以用 Canva、Blender、繪圖軟體，或請畫師製作。
- 某個檔案不存在時，遊戲會改用簡單的幾何圖形代替，不會當掉。
- 立繪建議約 600×900、透明背景。遊戲內精靈圖建議約 96×128。

## 自動測試模式

可以用指令列讓遊戲自己玩並截圖（自機無敵、自動射擊），方便檢查畫面：

```
UnrealEditor.exe DanmakuSTG.uproject -game -windowed -ResX=1280 -ResY=720 -DanmakuDemo -DanmakuSkip=99999 -DanmakuPhase=1 -DanmakuShotEvery=300 -DanmakuShots=6
```

- `-DanmakuSkip=N`：從道中第 N 幀開始（99999 會直接進 Boss 戰；Extra 用 3000 會從道中 Boss 開始）。
- `-DanmakuPhase=N`：Boss 從第 N 段開始。
- `-DanmakuStage=N`：以練習模式從第 N 面開始（0 = 第一面，6 = Extra）。
- `-DanmakuHPScale=0.1`：Boss 血量乘上這個倍率（測試用）。
- `-DanmakuHitTest`：測試模式下自機也會被打中（用來看雪的自動 Bomb）。
- `-DanmakuSpell=N`：直接開始符卡練習清單上的第 N 張（從 0 開始）；加上 `-DanmakuSpellSelect` 則是停在清單畫面、游標在第 N 張。
- 截圖存在 `Saved/DemoShots/`，拍完會自動關閉遊戲。

### 自動駕駛（AI 玩家）

`DanmakuBot.cpp` 是一個會自己打的 AI：每一幀預測半秒內所有子彈、雷射和敵人的位置，從 8 個方向＋停住、高速／低速、走到底／中途停下這些走法裡挑最安全、又能站在 Boss 下方的那一個；真的躲不掉才放 Bomb。它只讀遊戲狀態，而遊戲是固定時間步長、固定亂數種子，所以同一個指令每次都會打出一模一樣的過程。

- `-DanmakuDemo -DanmakuBot`：AI 自己打（會被打中）。打完會寫 `Saved/BotResult_<tag>.txt`（死亡、Bomb、在哪裡出事），名字用 `-DanmakuBotTag=名字` 指定。
- `-DanmakuTurbo=N`：每個 tick 跑 N 步，用來在背景快速測試（配合 `-nullrhi -nosound`）。蓮用滿血 AI 打 Lunatic、Extra、Extra-IF 都能 0 死通關。
- `-DanmakuBotSkill=1..5`：讓 AI 變弱（看得比較近、反應比較慢、手會滑；4、5 只會把子彈當直線預測），用來估計難度。
- `-DanmakuMeasure`：被打中不會死，只會計數。加上 `-DanmakuSweep -DanmakuSpell=0` 會把符卡練習清單從頭打到尾，每張符卡寫一行到 `Saved/BotSweep_<tag>.txt`：每分鐘被打中幾次，以及自機周圍 32／64 像素內平均有幾顆子彈。

符卡難度就是用這個調的：用三種程度的 AI 打完全部 63 張，太簡單（AI 幾乎不用動）的加強，太難（連好的 AI 都一直被打中）的減弱。另外也用 AI 比較了每張符卡在 Easy／Normal／Hard／Lunatic 的密度，把幾張幾乎不隨難度變化的符卡（土符、水符、五行、秋符、君子之約、第六面四張和四象歸一）改成會隨難度明顯加強（第六面用 `BeastK()`，Lunatic 的青龍多一條身體、白虎多一道爪擊）。目前刻意留下幾張特別難的（凶符「不退之陣」、「傲狠明德」、四神奧義「四象歸一」等），以及幾張道中 Boss 的簡單符卡。
